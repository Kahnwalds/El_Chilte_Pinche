### La propuesta

Un sitio rápido, bonito y fácil de usar donde cualquiera pueda encontrar, cocinar y preservar recetas del norte de México, con instrucciones claras y su historia.

---

## ✨ Funcionalidades

### MVP (en planeación)

- [ ] Listado de recetas con categorías (carnes, tortillas, guisos, salsas, postres…)
- [ ] Página de detalle de receta (ingredientes, pasos, tiempo, porciones)
- [ ] Búsqueda y filtros (ingrediente, tiempo, tipo de platillo)
- [ ] Diseño responsivo
- [ ] SEO básico y metadatos para compartir

### Ideas a futuro

- [ ] Ajuste automático de porciones
- [ ] Modo cocina (pantalla activa, pasos grandes)
- [ ] Favoritos y lista de compras
- [ ] Versión en inglés

> El alcance exacto del MVP se gestiona en el [tablero del proyecto](https://github.com/users/Kahnwalds/projects).

### Flujo de trabajo

- **Gestión:** tablero Kanban en [GitHub Projects](https://github.com/users/Kahnwalds/projects) (Backlog → Ready → In progress → In review → Done).
- **Ramas:** GitHub Flow. `main` está protegida; el trabajo se hace en ramas `feature/…`, `fix/…` o `docs/…`.
- **Commits:** [Conventional Commits](https://www.conventionalcommits.org/es/v1.0.0/) (`feat:`, `fix:`, `docs:`, `chore:`).
- **Pull Requests:** toda integración a `main` pasa por PR con revisión.

### Ejemplo

```bash
git checkout -b feature/listado-recetas
git commit -m "feat: agrega listado de recetas por categoría"
git push origin feature/listado-recetas
```
